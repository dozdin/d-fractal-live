# D-Fractal Live

Visualizador musical en un solo archivo HTML (WebGL2 + Web Audio), pensado para pantallas grandes de discoteca.

**Abrir la aplicación:** https://dozdin.github.io/d-fractal-live/

- Más de 100 escenas: fractales 2D y 3D, túneles, partículas, escenas interactivas, con tu texto y con cámara.
- Más de 60 efectos combinables, combos y más de 30 modos de DJ automático.
- Fuentes de audio: YouTube, archivos MP3, micrófono, captura de pestaña, demo y ritmo virtual.
- Sin dependencias ni compilación: basta con servir `index.html`.

Pulsa **H** para ocultar el panel y **F** para pantalla completa. La lista de atajos está en la pestaña Salida.
